# 财报数据解析

当用户上传财报PDF、粘贴财报数据，或说"帮我看看这份财报""提取一下XX的财务数据""这份年报说了什么"时触发本 Skill。

## 两种输入模式

### 模式A：用户上传PDF财报

按以下步骤处理，不要跳过：

1. **诊断PDF类型**
```bash
pdfinfo document.pdf          # 页数、文件大小
pdftotext -f 1 -l 1 document.pdf - | head -20  # 判断是文字PDF还是扫描件
```

2. **定位关键页面**（不要全文提取，只提取有用的页）
- 先提取目录页（通常第1-3页），找到以下章节的页码：
  - 合并利润表 / 综合收益表
  - 合并资产负债表
  - 合并现金流量表
  - 主营业务分部数据（分产品/地区）

3. **提取关键页面文本**
```python
import pdfplumber

with pdfplumber.open("document.pdf") as pdf:
    # 只提取目标页，不要全文
    target_pages = [利润表页码, 资产负债表页码, 现金流量表页码]
    for page_num in target_pages:
        page = pdf.pages[page_num - 1]
        # 优先用表格提取
        tables = page.extract_tables()
        if tables:
            for table in tables:
                print(table)
        else:
            print(page.extract_text())
```

4. **扫描件处理**（pdftotext返回空或乱码时）
```bash
pdftoppm -jpeg -r 150 -f {页码} -l {页码} document.pdf /tmp/page
# 然后用视觉读取图片
```

### 模式B：用户粘贴财报数据文字

直接从文字中提取结构化数据，标注数据出处（用户提供的文字）。

## ⛔ 最高优先级约束：严禁幻觉补充

财报PDF或用户粘贴的文字是唯一数据源。原文没有的数字、没有的业务、没有的同比数据，一律不得出现。即使你知道该公司的历史财务数据，也不得补充。字段缺失时填"原文未披露"。**财务数据的错误比没有数据更危险。**

---

## 提取重点

**第一优先：核心业绩（必提取）**
- 营业总收入：本期金额 + 同比增速
- 归母净利润：本期金额 + 同比增速
- 扣非净利润：本期金额 + 同比增速
- 毛利率：本期 + 同比变化（百分点）
- 净利率：本期 + 同比变化

**第二优先：盈利质量（必提取）**
- 经营活动现金流净额：与净利润对比（现金流/净利润 > 1 = 盈利质量高）
- 应收账款：本期金额 + 同比变化（大幅增加需预警）
- 存货：本期金额 + 同比变化（大幅增加需预警）

**第三优先：分部数据（有则提取）**
- 按产品/业务线拆分的收入和毛利率
- 按地区拆分的收入（国内/海外）

**第四优先：重要变化**
- 与上期相比变化超过20%的科目，单独标出
- 财报中管理层特别提示的风险或机会

## 注意事项

- **所有回复必须使用中文，严禁出现任何英文内容**
- 数据必须标注来源页码，如"（P.87）"
- 同比数据：有上期数据时计算增速，无上期数据时填"原文未披露上期数据"
- 毛利率变化用"pct"（百分点）而不是"%"，避免混淆
- 现金流/净利润比值：>1说明盈利质量好，<1需预警，原文未披露现金流时注明
- 超过20%变化的科目必须在"重要变化提示"里单独列出并给出原因（若原文有说明）
- 用户上传的如果不是财报（如研报、招股书），告知"这份文件是{文件类型}，不是财报，建议使用对应功能"
- 整体输出控制在55行以内，超出时优先保留核心业绩和重要变化，省略分部细节
