# financial-report-parse

> 用户上传财报 PDF（年报/季报/半年报）或粘贴财报数据时，从原始文件中提取关键财务数据。

## 触发场景

- "帮我看看这份财报"
- "提取一下 XX 的财务数据"
- "这份年报说了什么"
- 用户上传财报 PDF
- 用户粘贴财报原文文字

## 输出结构

- 标题：`## 📊 财报解析：{公司名}{报告期}`
- 核心业绩（营收 / 净利润 / 毛利率 / 同比）
- 盈利质量（现金流 / 应收账款 / 存货）
- 分部 / 业务拆分（如有）
- 重要变化提示
- 数据来源页码

## 涉及工具

- `pdfinfo` / `pdftotext` / `pdfplumber`（文字 PDF 处理）
- `pdftoppm` + 视觉读取（扫描件 PDF 处理）
- 无外部行情类 MCP 工具调用

## 示例输出

```markdown
## 📊 财报解析：比亚迪 2025年年报

**报告期**：2025-01-01 - 2025-12-31
**数据来源**：合并利润表（P.87）、合并现金流量表（P.91）、分部数据（P.103）

### 💰 核心业绩
| 指标 | 2025年 | 2024年 | 同比 |
| 营业总收入 | 8039.65亿元 | 7775.39亿元 | +3.46% |
| 归母净利润 | 326.19亿元 | 402.52亿元 | -18.97% |

### ⚠️ 重要变化提示
· 归母净利润同比下降 18.97%，主因毛利率收窄 1.68 个百分点
```

## 边界与注意

- **严禁幻觉补充**：原文没有的数字、业务、同比一律不得出现，缺失字段填"原文未披露"
- 数据必须标注来源页码（如 P.87）
- 毛利率变化用 `pct`（百分点），避免与 `%` 混淆
- 非财报文件（研报/招股书）告知用户走对应 skill
- 整体输出控制在 55 行以内
