# research-report-digest

> 用户上传研报 PDF、粘贴研报摘要或询问研报内容时，提炼机构观点和关键预测。

## 触发场景

- "帮我解读这份研报"
- "这个研报说了什么"
- "XX 的研报怎么看"
- "帮我提炼一下研报核心"
- 用户上传研报 PDF

## 输出结构

- 标题：`## 📋 研报解读：{股票/行业名}`
- 基本信息（机构 / 评级 / 目标价 / 日期）
- 🎯 核心结论（3 条以内）
- 📊 关键数据
- 💡 投资逻辑
- ⚠️ 风险因素
- 🔄 与前期预测对比（如有）
- 免责声明

## 涉及工具

- `read`（读取 PDF）
- `快讯列表`（查找同机构对同标的历史评级，做前期对比）

## 示例输出

```markdown
## 📋 研报解读：比亚迪（sz002594）

**发布机构**：中金公司 | **分析师**：XXX
**发布日期**：2026-04-20 | **评级**：买入 ⬆️（上调，前次：增持）
**目标价**：130元（12个月）| **现价**：101.53元 | **上行空间**：+28%

### 🎯 核心结论
· 一季度销量超预期，新能源乘用车市占率提升至 38%
· 出海业务加速，欧洲市场交付环比 +45%
· 刀片电池降本显现，预计全年毛利率回升至 19%
```

## 边界与注意

- **严禁幻觉补充**：原文没有的数据、分析、结论不得出现，缺失字段填"原文未披露"
- 评级变化用箭头：⬆️ 上调 / ➡️ 维持 / ⬇️ 下调
- 目标价必须标注货币单位和时间期限
- 非研报文件（如财报）告知走 financial-report-parse
- 整体输出控制在 50 行以内
