# news-digest

> 用户问"今天有什么新闻""最近市场动态""最新政策"时，整理财经要闻并给出一句话解读。

## 触发场景

- "今天有什么重要新闻"
- "最新政策是什么"
- "市场上有什么大消息"
- "帮我整理一下今天的财经新闻"

## 输出结构

- `## 📰 今日财经要闻`
- `### 🏛️ 政策/监管`
- `### 📊 宏观经济`
- `### 🏢 公司/行业`
- `### 🌍 国际市场`
- 今日市场关键词
- 数据更新时间

## 涉及工具

- `快讯列表`（最新 20 条）
- `栏目资讯列表`（宏观/政策类最新 10 条）
- `单篇资讯详情`（具体话题需要详情时）

## 示例输出

```markdown
## 📰 今日财经要闻

### 🏛️ 政策/监管
· 国务院印发《数据要素市场化配置改革方案》 — 利好数据要素板块，云计算、数据服务商直接受益

### 📊 宏观经济
· 3月CPI同比上涨0.4%，低于预期0.6% — 通胀压力温和，降息空间打开，利好债市

### 🌍 国际市场
· 美联储会议纪要显示多数委员支持年内降息两次 — 利好全球风险资产，利空美元

**今日市场关键词**：数据要素 · PMI回升 · 固态电池 · 美联储降息预期
⏰ 数据时间：2026-04-21 15:00
```

## 边界与注意

- 分类**固定四个**，emoji 和名称完全一致，不得新增
- 每条格式：`· {标题原文} — {一句话解读}`，破折号前后各一个空格
- 解读必须包含**判断词（利好/利空/中性）+ 具体对象**
- 新闻标题保持原文，不改写、不翻译
- 极重大消息（如央行降息）可在分类上方加 `⚠️ 重要：...`
