# 财经新闻解读

当用户问"今天有什么重要新闻""最新政策是什么""市场上有什么大消息""帮我整理一下今天的财经新闻"时触发本 Skill。

## 执行步骤

### 场景 A：宽泛问法

1. **并行**调用：`快讯列表`（最新20条）+ `栏目资讯列表`（宏观/政策类最新10条）
2. 从所有内容中挑选最重要的8条以内，每类最多3条
3. 按下方示例格式输出，一字不差地照抄结构

### 场景 B：具体话题

1. 调用 `快讯列表` 过滤相关内容，如有链接调用 `单篇资讯详情`
2. 按下方示例格式输出

**输出规则（对照示例执行）：**

1. 开头固定是 `## 📰 今日财经要闻`，不得改成其他标题
2. 分类固定只有四个，名称和emoji必须完全一致：
   - `### 🏛️ 政策/监管`
   - `### 📊 宏观经济`
   - `### 🏢 公司/行业`
   - `### 🌍 国际市场`
3. 每条新闻格式固定：`· {标题原文} — {一句话解读}`，破折号前后各一个空格
4. 一句话解读必须包含：**判断词**（利好/利空/中性）+ **具体对象**（板块/资产/市场）
5. 结尾固定两行：`**今日市场关键词**：xx · xx · xx` 和 `⏰ 数据时间：{时间}`
6. 某分类当日无重要新闻可省略该分类，但不得新增示例中没有的分类

## 分类判断规则

| 新闻类型 | 归入分类 |
|---------|---------|
| 国内央行、证监会、财政部、发改委等政策 | 🏛️ 政策/监管 |
| 国内GDP、CPI、PMI、就业、贸易等数据 | 📊 宏观经济 |
| 个股公告、行业动态、企业并购、机构评级 | 🏢 公司/行业 |
| 美联储、欧央行、外国政策、汇率、地缘政治、大宗商品 | 🌍 国际市场 |

## 一句话解读参考

解读是判断，不是复述标题。参考逻辑如下，需结合实际背景判断，不要机械套用：

- 降息/降准/宽松 → 通常利好股市、债市，但若因经济下行被迫降息，注明"需观察基本面"
- 加强监管/整顿 → 利空被监管行业
- 补贴/扶持 → 利好对应板块
- GDP/PMI超预期 → 利好大盘、周期股
- 通胀高于预期 → 货币政策收紧风险，利空成长股
- 地缘政治紧张 → 利好黄金、原油，利空风险资产
- 快讯只有标题时，解读保守，用"或"表示不确定（如"或利好新能源板块，待细则确认"）

## 注意事项

- **所有回复必须使用中文，严禁出现任何英文内容**
- 有一条新闻影响极其重大（如央行降息），在 `## 📰 今日财经要闻` 下方、四分类上方加一行 `⚠️ 重要：{标题} — {解读}`
- 新闻标题保持原文，不改写、不翻译
