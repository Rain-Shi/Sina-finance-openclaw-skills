# smart-research

> 用户提出复合型 / 开放性财经问题时使用（筛选、对比、综合判断、找机会）。

## 触发场景

- "新能源最近怎么样，有没有值得关注的股票"
- "今天哪个板块最热，龙头股是谁"
- "帮我找几只值得关注的股票"
- "茅台和比亚迪最近有什么消息，哪个更值得关注"
- "黄金和 A 股今天哪个更强"

## 输出结构

- 置信度标注（🟢 高 / 🟡 中 / 🔴 低）
- 核心结论（1-2 句话）
- 数据详情（表格或分维度列表）
- 💡 综合建议（关注型 / 积极型 / 保守型）
- ⚠️ 风险提示与数据缺口
- 🔜 可以继续问（2-3 个引导方向）

## 涉及工具

按意图选择组合，全部并行：

- `A股强势板块列表` / `A股指数和行业板块成分股` / `A股市场涨停池`
- `股票行情` / `全市场股票代码搜索`
- `A股公司财务指标`
- `快讯列表`
- `黄金综合期货` / `国内商品期货` / `获取最新汇率行情`（跨市场意图）

## 示例输出

```markdown
## 🔎 新能源板块研究快报

**置信度：🟢 高**
数据来源：股票行情、财务指标、快讯列表，获取时间：2026-04-21 15:30

**核心结论：** 板块整体回暖，龙头宁德时代领涨，建议关注但暂不追高。

### 💡 综合建议
· 关注型：可观察龙头量价配合
· 积极型：分批布局二线弹性标的
· 保守型：等待回踩 60 日线信号
```

## 边界与注意

- **与 stock-deep-analysis 互斥**：单股深度分析不走本 skill，停止并转 stock-deep-analysis
- **与 stock-compare 互斥**：纯两股对比走 stock-compare
- **与 stock-quick-query 互斥**：单股行情查询走 stock-quick-query
- 严禁用训练知识中的旧数据，必须工具实时获取
- 预算控制：轻量 ≤8 / 标准 ≤20 / 深度 ≤40 次工具调用
- 整体输出控制在 40 行以内
