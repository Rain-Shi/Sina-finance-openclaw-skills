# stock-compare

> 用户想对比两只或多只股票时使用（最多 5 只）。

## 触发场景

- "帮我对比茅台和五粮液"
- "茅台和比亚迪哪个更好"
- "XX 和 XX 的区别"
- "对比一下 A、B、C 三只股票"

## 输出结构

- 对比表格（行业 / 现价 / 涨跌 / 市值 / PE / PB / ROE / 净利润增速）
- 差异最大的指标加粗
- 逐只简评
- 跨行业 / 跨市场对比说明（如适用）

## 涉及工具

并行调用：

- `全市场股票代码搜索`（输入名称时）
- `股票行情`
- `A股公司财务指标` / `港股财务指标`
- `A股公司基础信息`（取所属行业）

## 示例输出

```markdown
## 茅台 vs 比亚迪 对比

| 指标 | 贵州茅台（sh600519） | 比亚迪（sz002594） |
| 所属行业 | 白酒 | 新能源汽车 |
| 现价 | 1418.5元 | 101.53元 |
| 市盈率PE | 22.4倍TTM | 28.4倍静态 |
| ROE | **31.6%** | 15.3% |
| 净利润增速 | +15.4% | **-19.0%** |

**简评：**
· 贵州茅台：ROE 行业顶尖，估值偏贵但业绩确定性强
· 比亚迪：新能源龙头规模领先，但 2025 年受价格战冲击

**跨行业说明：** 两者所属行业不同，PE/PB 不具备直接可比性。
```

## 边界与注意

- 最多 5 只，超过时告知用户
- 跨市场对比时市值统一换算为人民币亿元（港股÷汇率，美股×汇率），并备注汇率
- PE 异常值规则：负数填"亏损中"，>500 倍填"极高"，缺失填"暂无数据"
- 跨行业对比必须加"跨行业说明"提示 PE 不直接可比
- 必须先调用 `全市场股票代码搜索`，不让用户自己提供代码
