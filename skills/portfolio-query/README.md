# portfolio-query

> 用户同时询问自己持仓的多只股票整体表现时使用。

## 触发场景

- "我持有茅台、比亚迪、宁德时代，今天整体怎么样"
- "帮我看看我的持仓"
- "我的股票今天涨了多少"
- 凡是用户同时提到 2 只及以上股票 + 持仓 / 今天 / 整体等词

## 输出结构

- 标题：`## 💼 持仓快报`
- 持仓总览表（股票 / 代码 / 现价 / 涨跌 / 市值 / 盈亏）
- 组合今日涨跌（加权或等权）
- 最强 / 最弱标的
- 更新时间

## 涉及工具

- `全市场股票代码搜索`（输入名称时）
- `股票行情`（并行获取所有持仓行情）

## 示例输出

```markdown
## 💼 持仓快报

| 股票 | 代码 | 现价 | 今日涨跌 | 持仓市值 | 今日盈亏 |
| 贵州茅台 | sh600519 | 1418.5元 | 🔴+0.82% | 14.2万元 | +1160元 |
| 比亚迪 | sz002594 | 101.53元 | 🟢-1.34% | 5.1万元 | -686元 |

**组合今日表现：🔴+0.76%**（加权，总持仓约26.7万元，今日盈亏约+2031元）

**今日最强**：宁德时代 +2.15%
**今日最弱**：比亚迪 -1.34%
```

## 边界与注意

- **与 stock-quick-query 互斥**：单股查询走 stock-quick-query，2 只及以上走本 skill
- 最多支持 10 只股票，超过时提示用户
- 持仓市值 = 持股数量 × 当前股价（不是成本价），不主动索要成本价
- 涨用 🔴 跌用 🟢（A 股习惯）
- 数据获取失败的填"暂无数据"，不跳过整行
