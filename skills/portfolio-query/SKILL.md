# 持仓组合快报

当用户说"我持有XX、XX、XX今天怎么样""帮我看看我的持仓""我的股票今天表现"时触发本 Skill。

## 执行步骤

### 第一步：提取持仓信息

从用户输入中识别：
- 股票名称或代码
- 持仓数量或金额（如有）
- 成本价（如有）

**未提供持仓数量时：** 只看今日涨跌，不计算盈亏金额，告知用户"如需计算今日盈亏金额，请告诉我各股持仓数量"。

### 第二步：并行获取所有股票行情

对用户持仓的每只股票同时调用：
- `全市场股票代码搜索`（名称输入时）
- `股票行情`：现价、涨跌幅、成交量

**全部并行，不串行等待。**

### 第三步：计算组合表现

**有持仓金额时（加权计算）：**
```
每只股票今日贡献 = 持仓市值 × 涨跌幅
组合今日涨跌幅 = Σ(每只股票今日贡献) ÷ 总持仓市值
```

**无持仓金额时（简单平均）：**
```
组合今日涨跌幅 = 所有股票涨跌幅的平均值
并注明"以下为等权平均，非加权结果"
```

## 注意事项

- **所有回复必须使用中文，严禁出现任何英文内容**
- 最多支持10只股票，超过时告知"建议一次查询不超过10只"
- 涨用🔴，跌用🟢，平盘用➖（A股习惯）
- 持仓市值 = 用户提供的持股数量 × 当前股价，不是用户的成本价
- 今日盈亏 = 持仓市值 × 涨跌幅，不是总浮盈浮亏
- 不主动要求用户提供成本价，这是隐私敏感信息
- 数据获取失败的股票填"暂无数据"，不跳过整行
