# stock-quick-query

> 用户询问单只股票现价、涨跌、行情时使用。

## 触发场景

- "茅台多少钱"
- "XX 今天涨了吗"
- "港股腾讯现价"
- "苹果现在多少"
- "XX 有什么消息"

## 输出结构

- 股票名 + 代码
- 现价 + 涨跌 emoji（🔴 涨 / 🟢 跌）
- 今日开盘 / 最高 / 最低
- 成交额 + 活跃度判断
- 交易时段标注（盘中 / 收盘 / 休市 / 集合竞价）
- 最新消息（用户问到时）

## 涉及工具

- `全市场股票代码搜索`（输入名称时）
- `股票行情`
- `快讯列表`（用户问及消息时）

## 示例输出

```markdown
**贵州茅台（sh600519）**
现价：1418.5元（收盘价）  🔴+0.82%（+11.5元）

今日：开盘 1406.0 | 最高 1425.0 | 最低 1402.3
成交额：43.28亿  🔥 成交活跃

📰 最新消息：
· 茅台2025年报营收利润双增，超市场预期
· 渠道调研：飞天茅台批价稳定在2150元附近
```

## 边界与注意

- **与 portfolio-query 互斥**：用户同时询问 2 只及以上股票持仓走 portfolio-query
- 涨用 🔴 跌用 🟢（A 股习惯，与 forex-query 相反）
- 必须先调用 `全市场股票代码搜索`，不让用户自己提供代码
- 成交活跃阈值按市值分档：大盘股 >50 亿 / 中盘股 >10 亿 / 小盘股 >3 亿
- 不输出原始 JSON 和工具调用过程
