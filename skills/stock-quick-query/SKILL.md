# 单股快速查询

当用户问"XX现在多少钱""XX今天怎么样""XX有什么消息"时触发本 Skill。

## 执行步骤

### 第一步：确认股票代码

- 如果用户说的是股票名称（如"茅台""腾讯""苹果"），先调用 `全市场股票代码搜索` 工具获取股票代码。
- 如果用户已经给出代码，直接使用（注意加市场前缀）。
- A股代码格式：沪市加 `sh` 前缀，深市加 `sz` 前缀
  - 示例：`sh600519`（茅台）、`sz000858`（五粮液）、`sz000001`（平安银行）
- 港股代码格式示例：`00700`
- 美股代码格式示例：`AAPL`、`TSLA`

**常见沪深市场判断规则：**
- 代码以 `6` 开头 → 沪市，加 `sh` 前缀
- 代码以 `0` 或 `3` 开头 → 深市，加 `sz` 前缀

### 第二步：获取实时行情

调用 `股票行情` 工具，传入股票代码，获取：
- 当前价格
- 涨跌额和涨跌幅
- 成交量和成交额
- 今日最高价、最低价、开盘价

### 第三步：判断交易时段

根据当前北京时间判断交易状态，在输出中标注：

| 时间段 | 状态 | 标注方式 |
|--------|------|---------|
| 9:15-9:25 | 集合竞价 | 在价格后注明"（集合竞价中，非最终开盘价）" |
| 9:30-11:30 / 13:00-15:00 | 盘中 | 不需要标注 |
| 15:00后 / 节假日 | 已收盘 | 在价格后注明"（收盘价）" |
| 9:25前 / 非交易日 | 盘前 | 注明"（上一交易日收盘价，今日尚未开盘）" |

### 第四步：获取最新快讯（可选）

如果用户明确问到"有什么消息""最近怎么了"，调用 `快讯列表` 工具，用股票名称或代码过滤，取最新 3 条。

## 输出格式

以下是完整示例，照抄结构，只替换数据：

**贵州茅台（sh600519）**
现价：1418.5元（收盘价）  🔴+0.82%（+11.5元）

## 成交活跃判断规则

不同类型股票的"成交活跃"阈值不同，避免一刀切：

| 股票类型 | 活跃阈值 | 判断依据 |
|---------|---------|---------|
| 沪深主板大盘股（市值>500亿） | 成交额>50亿 | 大盘股流动性高，50亿以上才算活跃 |
| 中小盘股（市值100-500亿） | 成交额>10亿 | 中盘股正常水平 |
| 科创板/创业板小盘股（市值<100亿） | 成交额>3亿 | 小盘股流动性低，3亿即算活跃 |

若无法判断市值，默认用20亿作为活跃阈值。

## 注意事项

- **所有回复必须使用中文，严禁出现任何英文内容**
- 用户输入股票名称时必须先调用 `全市场股票代码搜索`，不得要求用户自行提供代码
- 涨用 🔴，跌用 🟢，平盘用 ➖（符合A股用户习惯：红涨绿跌）
- 不要输出原始JSON，不要输出工具调用过程，只给用户看结果
- 如果股票代码搜索无结果，告知用户"未找到该股票，请确认名称或代码是否正确"
