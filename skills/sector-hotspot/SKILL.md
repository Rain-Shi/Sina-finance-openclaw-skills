# 板块热点追踪

当用户问"白酒板块今天怎么样""新能源最近热不热""哪些板块在涨""XX 概念股有哪些"时触发本 Skill。

## 两种场景

### 场景 A：用户问"哪些板块在涨"（没有指定板块）

**执行步骤：**

1. 调用 `A股强势板块列表`，获取今日强势板块排行，取前3名
2. 对前3名板块，调用 `A股指数和行业板块成分股` 获取成分股列表
3. **限流规则：每个板块只取涨幅前5只成分股**调用 `股票行情`，不要对全部成分股调用（防止成分股超过100只时工具调用过载）
4. 每个板块并行调用，3个板块共最多调用15次行情工具

**输出格式说明：只展开前3名板块+龙头股详情，禁止用表格列出所有板块排行。**

**输出格式示例（照抄结构）：**

### 场景 B：用户问某个具体板块（如"白酒板块""新能源"）

**板块名称模糊匹配规则：**

| 用户说 | 匹配范围 |
|--------|---------|
| 白酒 | 白酒、酿酒 |
| 新能源 | 新能源汽车、光伏、储能、风电 |
| 半导体/芯片 | 半导体、芯片、集成电路 |
| 医药/医疗 | 医药生物、医疗器械、创新药 |
| 银行/金融 | 银行、券商、保险 |
| 消费 | 食品饮料、商贸零售、家电 |

找不到精确匹配时：列出最相近的3个板块，回复格式为：
"未找到'{用户输入}'的精确板块，您是想查以下哪个？
1. {板块名A}
2. {板块名B}
3. {板块名C}
请回复数字选择。"

**执行步骤：**

**必须严格按以下步骤调用工具，不得跳过任何一步，不得仅凭已知信息直接回答：**

1. 调用 `A股虚拟板块列表` 或 `A股强势板块列表` 查找匹配板块，获取板块整体涨跌幅
2. 调用 `A股指数和行业板块成分股` 获取成分股完整列表，**从中取涨幅前5和跌幅前3共8只**
3. 对这8只**并行**调用 `股票行情`，获取每只的现价和涨跌幅
4. 调用 `快讯列表`，过滤该板块相关新闻，取最新3条

以上4步全部完成后才能输出结果，中途不得提前输出任何分析内容。

**输出格式示例（照抄结构）：**

## 注意事项

- **所有回复必须使用中文，严禁出现任何英文内容**
- 场景A每个板块最多调用5只成分股行情，场景B最多调用8只，严格限流不得突破
- 成分股超过30只时，只取涨幅排行前5和末3，不要全部列出
- 龙头股的"一句话说明"只在有明确原因时写（如业绩/消息），没有明确原因时留空，不要强行解读
