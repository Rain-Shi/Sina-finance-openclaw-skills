# sector-hotspot

> 用户询问板块表现、哪些板块在涨、概念股行情时使用。

## 触发场景

- "白酒板块今天怎么样"
- "新能源最近热不热"
- "哪些板块在涨"
- "XX 概念股有哪些"
- "今天板块热点"

## 输出结构

**场景 A（未指定板块）：**
- `## 🏆 今日强势板块`
- 前 3 名板块各含龙头股详情（每个板块取涨幅前 5）

**场景 B（指定板块）：**
- 板块整体涨跌
- 涨幅 TOP 5 表格
- 今日垫底（跌幅前 3）
- 相关消息

## 涉及工具

- `A股强势板块列表`
- `A股虚拟板块列表`
- `A股指数和行业板块成分股`
- `股票行情`（并行查成分股）
- `快讯列表`（板块相关新闻）

## 示例输出

```markdown
## 🏆 今日强势板块

### 第1名：复合铜箔 整体涨幅 8.3%
龙头股：
· 方邦股份（sh688020） 🔴+20.00% — 涨停，复合铜箔龙头受技术迭代预期催化
· 德福科技（sz301511） 🔴+15.04% — 铜箔出货量超预期，机构加仓明显
· 宝明科技（sz002992） 🔴+7.68% — 跟随板块情绪上涨
```

## 边界与注意

- **严格限流**：场景 A 每板块最多 5 只行情，场景 B 最多 8 只，不得突破
- 板块名称模糊匹配（如"新能源"→新能源汽车/光伏/储能/风电），匹配不到列 3 个相近选项让用户确认
- 龙头股的"一句话说明"只在有明确原因时写，没有原因留空
- 必须先调工具再输出，不得仅凭已知信息直接回答
