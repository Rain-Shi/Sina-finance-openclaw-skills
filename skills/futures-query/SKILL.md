# 期货快查

当用户问"黄金今天怎么样""原油期货涨了吗""股指期货多少""铜期货行情"时触发本 Skill。

## 品种分类与工具对应

| 用户说 | 品种 | 调用工具 |
|--------|------|---------|
| 黄金、金价、Au | 黄金期货 | `黄金综合期货` |
| 原油、石油、WTI、布伦特 | 原油期货 | `国内商品期货` |
| 铁矿石、铁矿 | 铁矿石期货 | `国内商品期货` |
| 螺纹钢、螺纹 | 螺纹钢期货 | `国内商品期货` |
| 铜、沪铜 | 铜期货 | `国内商品期货` |
| 大豆、豆粕、豆油 | 农产品期货 | `国内商品期货` |
| 股指、沪深300期货、IF、IC、IM | 股指期货 | `金融期货` |
| 国债期货、T、TF | 国债期货 | `金融期货` |

## 执行步骤

### 单品种查询

1. 根据用户说的品种，判断调用哪个工具
2. 调用对应工具，获取**主力合约**行情
3. **主力合约换月检测**：若工具返回的主力合约持仓量或成交量明显低于次主力合约（低于50%），在输出中注明"当前主力合约可能已切换，数据仅供参考，建议关注换月情况"
4. 如果用户问黄金，**并行**获取国内期货价（Au主力，单位：元/克）和国际金价（COMEX，单位：美元/盎司），然后按以下公式计算内外盘价差：

**黄金内外盘价差换算公式：**
```
COMEX金价（美元/盎司）÷ 31.1035 × 美元兑人民币汇率 = 理论国内价格（元/克）
内外盘价差 = 国内期货实际价格 - 理论国内价格
价差 > 0：内盘升水（国内比国际贵）
价差 < 0：内盘贴水（国内比国际便宜）
```
汇率从本次对话的外汇工具获取，若无可用汇率数据，使用近似值7.2并注明"汇率为近似值"。

**数据缺失时的 fallback 规则（重要）：**
- 若国内期货价格接口失败，**不要等待或放弃**，立即用 COMEX 数据 + 近似汇率7.2 计算理论国内价，输出时注明"国内行情接口暂时不可用，以下为参考估算值"
- 若 COMEX 数据也获取失败，则说明"两路数据均暂不可用，请稍后重试"，不留空白
- 若汇率工具失败，直接使用7.2，无需重试
- **任何单一接口失败都不应导致整条回复空白**，用现有数据给出尽可能完整的回答

### 多品种同时查（如"帮我看看今天大宗商品"）

并行调用 `黄金综合期货`、`国内商品期货`（原油/铜/铁矿石/螺纹钢），汇总成一张总览表。

## 涨跌颜色规则

期货市场沿用A股习惯：**红色代表上涨，绿色代表下跌**。
- 上涨用 🔴，下跌用 🟢，平盘用 ➖

## 注意事项

- **所有回复必须使用中文，严禁出现任何英文内容**
- 优先查**主力合约**，不要查近月合约（避免临近交割时数据异常）
- 黄金内外盘价差必须通过上述公式计算，**严禁直接用元/克价格减去美元/盎司价格**（单位不同，直接相减无意义）
- 如果用户问"黄金涨了是因为什么"，调用 `快讯列表` 补充相关新闻
- 股指期货（IF/IC/IM/IH）涨跌与A股大盘高度相关，可以联动说明"与现货大盘基本同步"
- 不要显示合约到期日，普通用户不需要这个信息
- **农产品季节性提示**：豆粕/豆油在每年3-5月（南美大豆收割季）和8-10月（北美大豆收割季）价格波动较大；如用户问及农产品期货，可简短提示当前是否处于季节性敏感期
