# futures-query

> 用户询问期货行情时使用，覆盖黄金、原油、铁矿石等商品期货和股指、国债等金融期货。

## 触发场景

- "黄金今天怎么样"
- "原油期货涨了吗"
- "股指期货多少"
- "铜期货行情"
- "帮我看看今天大宗商品"

## 输出结构

- 品种 + 主力合约代码
- 现价 + 单位 + 涨跌
- 今日开盘 / 最高 / 最低
- 持仓量 + 成交量
- 黄金类须加内外盘价差换算

## 涉及工具

- `黄金综合期货`（黄金）
- `国内商品期货`（原油 / 铜 / 铁矿石 / 螺纹钢 / 农产品）
- `金融期货`（股指 / 国债）
- `快讯列表`（问及行情原因时补充）

## 示例输出

```markdown
**黄金期货（主力合约：Au2506）**
国内金价：685.20 元/克  🔴+0.83%（+5.65）

今日：开盘 680.10 | 最高 687.00 | 最低 679.50
持仓量：12.3万 手 | 成交量：48.5万 手

国际金价（COMEX）：2965.00 美元/盎司  +0.91%
内外盘价差：+1.20 元/克（内盘升水）
换算说明：COMEX 2965 ÷ 31.1 × 7.23 ≈ 689.4 元/克

⏰ 更新时间：2026-04-21 15:30
```

## 边界与注意

- 期货沿用 A 股习惯：🔴 涨 / 🟢 跌（与 forex-query 相反）
- 黄金内外盘价差**必须用换算公式**，严禁直接用元/克 - 美元/盎司
- 优先查主力合约，不查近月（避免交割异常）
- 接口失败有 fallback：单一接口失败不应导致整条回复空白
