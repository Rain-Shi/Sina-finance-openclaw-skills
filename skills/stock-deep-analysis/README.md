# stock-deep-analysis

> 单只股票的综合深度分析，覆盖基本面、技术面、资金面、消息面。

## 触发场景

- "帮我分析一下 XX"
- "XX 值不值得关注"
- "XX 的基本面怎么样"
- "给我一份 XX 的研究报告"

## 输出结构

> 备注：本 skill 的 description 不含 ①②③ 骨架——骨架放在 SKILL.md 正文中分阶段注入，原因是多步工具调用（A 股/港股/美股市场判断 + 多维度数据汇总）后才能形成完整结构。

输出包含以下分维度模块：

- 标题：`## {股票名}（{代码}）深度分析`
- `### 📋 基本信息`（行业 / 上市日期 / 总市值 / 现价）
- `### 💰 基本面`（PE / PB / ROE / 净利润 / 营收 + **判断**）
- `### 📈 技术面`（趋势 / 量价关系 / 支撑压力位 + **判断**）
- `### 💼 资金面`（融资余额变化 + **判断**）
- `### 📰 消息面`（最新 5 条快讯 + **判断**）
- `### 🎯 综合小结`

## 涉及工具

按市场选择，全部并行：

- `全市场股票代码搜索`
- `股票行情`
- `A股公司基础信息` / `A股公司财务指标` / `A股公司主营构成` / `A股股票融资融券`（A 股）
- `港股财务指标`（港股）
- `全市场股票日K`（近 60 日 K 线）
- `快讯列表`

## 示例输出

```markdown
## 贵州茅台（sh600519）深度分析

### 💰 基本面
PE：22.4倍TTM（行业均值约18倍）| PB：7.2 | ROE：31.6%（最新年报）
净利润：857亿（同比+15.4%）| 营收：1741亿（同比+16.2%）

**判断**：估值偏高，基本面优质。ROE 连续多年超 30%，但 PE 高于行业均值 24%。

### 📈 技术面
近期走势：震荡
量价关系：缩量下跌
支撑位：1380元 | 压力位：1460元
```

## 边界与注意

- **与 smart-research 互斥**：smart-research 遇单股分析时停止并转本 skill
- 每个维度都必须给"**判断**"文字，只列数据视为不完整
- 港股/美股无融资融券，用成交量变化替代；美股财务可能不可用，需注明
- 财务数据必须标注期次（最新年报/最新季报），PE 必须标 TTM 还是静态
- 整体输出控制在 45 行以内
