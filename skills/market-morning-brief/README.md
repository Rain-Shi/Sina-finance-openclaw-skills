# market-morning-brief

> 用户问"今天大盘""市场早报""行情怎么样"时生成 A 股市场整体快报。

## 触发场景

- "今天大盘怎么样"
- "今天市场行情"
- "给我一个早报"
- "今天涨停多不多"

## 输出结构

- 标题：`## 📊 今日A股市场快报`
- 市场情绪：XX + 上涨 / 下跌 / 平盘家数
- 三大指数（上证 / 深证 / 创业板）涨跌幅
- `### 🔴 涨停情况`（涨停数量 + 连板榜）
- `### 🏆 强势板块 TOP 5`
- `### 📰 今日要闻`
- `⏰ 数据更新时间`

## 涉及工具

5 个工具必须**全部并行**调用：

- `A股全市场涨跌分布统计`
- `A股市场涨停池`
- `A股强势板块列表`
- `快讯列表`
- `股票行情`（上证 sh000001 / 深证 sz399001 / 创业板 sz399006）

## 示例输出

```markdown
## 📊 今日A股市场快报
（今日收盘数据）

**市场情绪：震荡**
上涨 2341 家 | 下跌 2108 家 | 平盘 143 家

**三大指数**
上证指数 3287.5 🟢-0.32% | 深证成指 9876.4 🔴+0.15% | 创业板指 1923.7 🔴+0.68%

### 🔴 涨停情况
今日涨停 **87** 只，其中连板股 **12** 只
```

## 边界与注意

- 情绪判断需**同时**参考上涨家数比例和指数涨跌，可输出"分化""指数强个股弱"等修正标签
- 快讯只取宏观 / 政策 / 指数类，不取个股新闻
- 5 个工具全部返回后才能输出，缺一不可
- 整个早报控制在 25 行以内
