# 今日市场早报

当用户问"今天大盘怎么样""今天市场行情""给我一个早报""今天涨停多不多"时触发本 Skill。

## 执行步骤

**以下5个工具必须全部调用，缺少任何一个视为不完整输出，全部并行发起不要串行：**

1. `A股全市场涨跌分布统计`：获取今日全市场上涨/下跌/平盘家数
2. `A股市场涨停池`：获取今日涨停股列表，重点看涨停数量和连板情况
3. `A股强势板块列表`：获取今日表现最强的板块，取前5名 ← **不得跳过**
4. `快讯列表`：获取今日最重要的市场快讯，取前5条 ← **不得跳过**
5. `股票行情`：获取上证指数（sh000001）、深证成指（sz399001）、创业板指（sz399006）三大指数行情

**5个工具全部返回数据后，才能开始生成输出。不得在工具调用完成前输出任何内容。**

## 市场情绪判断规则

情绪判断需**同时参考**上涨家数比例和指数涨跌，两者综合判断：

**第一步：根据上涨家数比例初判**
- ≥ 60%：强势
- 45%~60%：震荡
- 30%~45%：偏弱
- < 30%：大跌

**第二步：根据指数涨跌修正**
- 若上涨家数比例高（≥55%）但三大指数全部下跌：修正为"分化"（赚指数不赚钱/赚钱不赚指数）
- 若上涨家数比例低（<45%）但指数上涨：修正为"指数强、个股弱"
- 两者一致时，直接用第一步结论

**第三步：输出情绪标签**
综合以上给出一个情绪词：强势 / 震荡 / 分化 / 偏弱 / 大跌 / 指数强个股弱

## 交易时段判断

根据当前北京时间，在输出开头加对应标注：

| 时间段 | 标注 |
|--------|------|
| 工作日 9:30-15:00 | 不标注，直接输出实时数据 |
| 工作日 15:00后 | 标注"（今日收盘数据）" |
| 工作日 9:30前 | 标注"（盘前，以下为上一交易日收盘数据）"，并注明"今日预计X点开盘" |
| 周末/节假日 | 标注"（今日休市，以下为上一交易日收盘数据）"，并注明"下一交易日为X月X日" |

涨停池数据为空时：说明"今日非交易日或涨停数据暂未更新"，不要留空。
