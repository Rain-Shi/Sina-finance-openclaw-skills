# forex-query

> 用户询问汇率、外汇行情、人民币兑换时使用，支持主要货币对实时查询和换算。

## 触发场景

- "美元现在多少"
- "人民币对日元"
- "最近汇率怎么样"
- "我换 1000 美元需要多少人民币"
- "帮我看看主要货币汇率"

## 输出结构

- 货币对名称
- 当前汇率 + 涨跌幅
- 今日最高 / 最低
- 换算结果（如有）
- 更新时间
- 批量查询用表格展示

## 涉及工具

- `获取最新汇率行情`
- `批量外汇行情`

## 示例输出

```markdown
**美元兑人民币（USD/CNY）**
当前汇率：1 USD = 7.2341 CNY  🟢+0.12%

今日：最高 7.2490 | 最低 7.2180
换算：1000 USD ≈ 7234.1 CNY

⏰ 更新时间：2026-04-21 15:30
```

## 边界与注意

- 外汇用**国际惯例**：🟢 涨 / 🔴 跌（与 A 股相反），用户疑惑时主动说明
- 日元 / 韩元用 100 单位展示，越南盾 / 印尼盾用 1000 单位展示，不得直接显示小数
- 换算场景必须直接给精确结果，不让用户自己算
- 不输出原始工具字段名，全部中文化
