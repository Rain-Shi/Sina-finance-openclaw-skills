# 汇率/外汇查询

当用户问"美元现在多少""人民币对日元""最近汇率怎么样""我换X美元需要多少人民币"时触发本 Skill。

## 常用货币代码对照

| 用户说 | 代码 | 展示单位 |
|--------|------|---------|
| 美元 | USD | 1 USD = X CNY |
| 欧元 | EUR | 1 EUR = X CNY |
| 日元 | JPY | 100 JPY = X CNY（日元必须用100单位展示）|
| 英镑 | GBP | 1 GBP = X CNY |
| 港元 | HKD | 1 HKD = X CNY |
| 韩元 | KRW | 100 KRW = X CNY（韩元必须用100单位展示）|
| 澳元 | AUD | 1 AUD = X CNY |

| 越南盾 | VND | 1000 VND = X CNY（越南盾必须用1000单位展示）|

| 印尼盾 | IDR | 1000 IDR = X CNY（印尼盾必须用1000单位展示）|

## 涨跌颜色规则

外汇查询统一用国际惯例：**绿色代表上涨，红色代表下跌**（与A股相反）。
- 上涨用 🟢，下跌用 🔴，平盘用 ➖

## 执行步骤

### 场景 A：查单个货币对

1. 调用 `获取最新汇率行情`，查询该货币对人民币的汇率
2. 同时调用 `批量外汇行情` 获取今日最高/最低/涨跌幅

### 场景 B：批量查多个货币（如"帮我看看主要货币汇率"）

1. 调用 `批量外汇行情`，一次性获取 USD/EUR/JPY/GBP/HKD/AUD 对人民币的汇率

### 场景 C：换算金额（如"1000美元能换多少人民币"）

1. 获取实时汇率
2. 直接计算：金额 × 汇率 = 结果，给出精确数字

### 场景 D：用户问走势（如"最近人民币在升值还是贬值"）

1. 调用 `获取最新汇率行情` 获取近期数据
2. 对比近期高低点，给出一句趋势判断

## 注意事项

- **所有回复必须使用中文，严禁出现任何英文内容**
- 日元/韩元/越南盾/印尼盾必须用对应单位展示，不得直接显示小数（如0.048）
- 外汇涨跌用国际惯例（🟢涨🔴跌），与A股相反，如用户疑惑可主动说明
- 换算场景直接给精确结果，不要让用户自己计算
- 用户问"人民币在升值还是贬值"时：汇率数字变小=人民币升值，汇率数字变大=人民币贬值，用通俗语言解释
- 不要显示原始工具返回的字段名，全部换成中文
